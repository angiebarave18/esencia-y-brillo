# Esencia & Brillo · Tienda en línea (simulación)

Prototipo de tienda en línea para el emprendimiento **Esencia & Brillo** (fragancias, joyería, bisutería, accesorios y regalos para mujer, San Pedro Sula, Honduras).

Proyecto de **Comercio Electrónico · Grupo 2** — Maestría en Dirección Empresarial y Comercio Internacional, UTH (2026).

- Sitio: https://angiebarave18.github.io/esencia-y-brillo/
- Todo el sitio está en `index.html` (HTML + CSS + JS).
- Las fotos de `img/` son imágenes genéricas sin marca de [Unsplash](https://unsplash.com/license) y [Pexels](https://www.pexels.com/license/) (licencias libres). Se descargan con el flujo `.github/workflows/fotos.yml`.
- Productos, precios y testimonios son **de ejemplo** para la simulación.
- Pedido sin pago en línea: la selección se envía por WhatsApp. El número se configura en `WA_NUMERO` dentro de `index.html`.
